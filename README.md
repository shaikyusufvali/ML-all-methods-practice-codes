## Important Notes
- fit() trains the model.
- predict() generates predictions.
- transform() transforms data.
- fit_transform() fits a transformer and transforms data.
- predict_proba() returns probabilities when supported.
- score() returns a model-specific score.
- Scaling is generally important for KNN and SVM.
- Tree-based models usually do not require scaling.
- Fit preprocessing steps only on training data.
- Choose regression metrics for regression tasks.
- Choose classification metrics for classification tasks.
- Not every model supports every method.
- Practice each algorithm with a real dataset.
